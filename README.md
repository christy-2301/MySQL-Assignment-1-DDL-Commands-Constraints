 MySQL Assignment 1 – DDL Commands & Constraints

This project demonstrates the use of MySQL DDL commands and constraints by creating and managing an Employee Database.

Topics Covered
- Database and table creation
- Table alteration using ALTER
- Table renaming
- Table truncation
- Table and database dropping
- PRIMARY KEY
- NOT NULL
- UNIQUE
- AUTO_INCREMENT
- ENUM
- CHECK
- DEFAULT
- FOREIGN KEY
